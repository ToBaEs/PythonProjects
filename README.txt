HAS Project is a Linux-native surveillance and recording utility developed with Python and OpenCV.
It is designed to monitor live video streams, detect motion patterns, and initiate synchronized audio/video recording based on environmental triggers.

🗺️Roadmap & Future Enhancements
The project is continuously evolving. The following modules are planned for future releases:

AI-Powered Object Recognition: Integrating Deep Learning models to distinguish between humans, animals, and vehicles, significantly reducing false-positive motion triggers.

Multi-Camera Support: A synchronized monitoring system capable of viewing and recording from multiple camera streams simultaneously.

Advanced Device Customization: An interface to dynamically select and configure specific microphones and cameras, allowing for granular control over hardware inputs.

Smart Storage Management: A monitoring system that automatically tracks disk space and manages old recordings to ensure system stability and prevent storage-related crashes.

Enhanced User Interface (UI): Development of a modern dashboard for real-time monitoring and easier access to system settings.
